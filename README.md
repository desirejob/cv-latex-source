# Curriculum vitae

This private repository contains the LaTeX source and a locally compiled PDF of my curriculum vitae.

## Files

- `CV_Desire_Job_Hayang_aims.tex` — editable LaTeX source.
- `CV_Desire_Job_Hayang_aims.pdf` — compiled document.

## Build

With a LaTeX distribution installed, run:

```sh
pdflatex CV_Desire_Job_Hayang_aims.tex
```

The source and compiled document contain personal contact information. Keep this repository private and review both before sharing or changing its visibility.
